# Agency Workflow

## Daily Operations

### Morning (7:00 AM)
1. **AI Daily Briefing** - Executive summary of new opportunities
2. **Pipeline Review** - Hot leads, tasks due, follow-ups
3. **Provider Health** - Check provider status

### During Day
1. **Discovery Runs** - Auto-discover new businesses
2. **Audits Complete** - Website analysis done
3. **Scores Generated** - Leads prioritized by opportunity
4. **Outreach Prep** - AI-generated emails ready

### Evening (5:00 PM)
1. **Progress Update** - Campaign completion stats
2. **Pipeline Changes** - Leads moved between stages
3. **Tasks Due** - Follow-ups, meetings

## Lead Lifecycle

### 1. Discovery
- Campaign searches cities × industries
- Providers return business listings
- Deduplication removes duplicates

### 2. Audit
- Website fetch and analysis
- 17 automated checks
- AI content analysis
- Score generation (0-100)

### 3. Qualification
- Lead scoring (hot/warm/cold)
- Opportunity detection
- Service recommendation
- Pricing estimation

### 4. Outreach
- AI-generated cold email
- LinkedIn connection message
- WhatsApp message
- Follow-up sequence (5 emails)

### 5. Pipeline
- New → Qualified → Contacted → Meeting → Proposal → Won/Lost
- Activities logged
- Tasks created
- Notes added

### 6. Close
- Proposal sent
- Follow-ups scheduled
- Win probability tracked
